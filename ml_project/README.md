# MLOps Pipeline Example

This project demonstrates a modular MLOps pipeline.

## Training

```bash
python ml_project/scripts/train_model.py
```

## Serving

```bash
python ml_project/scripts/serve_model.py
```

## Testing

```bash
python ml_project/scripts/run_tests.py
```

Ensure dependencies are installed using `pip install -r ml_project/requirements.txt`.
