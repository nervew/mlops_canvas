# Código de Conducta

**Principios:** respeto, inclusión, profesionalismo; cero tolerancia a acoso o lenguaje ofensivo.

**Ámbito:** repo, issues, PRs, eventos y canales de chat.

**Esperado:** feedback constructivo, reconocimiento del trabajo ajeno, respeto cultural.

**Inaceptable:** ataques personales, trolling, compartir información sensible, sabotear debates técnicos.

**Consecuencias:** mantenedores pueden borrar comentarios, revertir contribuciones o bloquear cuentas.

**Reportes:** escribe a `conduct@example.com` con incidente, participantes y evidencias (SLA <5 días hábiles).

**Rutas:** Principiante → revisa ejemplos positivos; Experta → mentorea y modera.
