|---------|------------|
| AML | Azure Machine Learning para entrenar/desplegar modelos. |
| ADLS Gen2 | Almacenamiento optimizado para analítica. |
| AKS | Azure Kubernetes Service para contenedores. |
| MLflow | Seguimiento de experimentos y artefactos. |
| PSI | Population Stability Index, mide drift. |
| CI/CD | Integración y despliegue continuos. |
| ADR | Architecture Decision Record. |
| HPA | Horizontal Pod Autoscaler. |
| Private Endpoint | Conexión privada a servicios PaaS. |
