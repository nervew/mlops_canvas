# STYLEGUIDE.md

**Python:** `black` (88) + `isort`, usar `from __future__ import annotations`, no envolver imports en `try/except`.

**IaC:** `terraform fmt`, nombres `<app>-<env>-<tipo>`.

**Docs:** español neutro, bloques Principiante/Experta, diagramas Mermaid.

**Commits/PRs:** Conventional Commits, resume impacto y métricas, enlaza runbooks/dashboards cuando cambien.

**Rutas:** Principiante → respeta plantilla de PR; Experta → referencia ADRs relevantes.
